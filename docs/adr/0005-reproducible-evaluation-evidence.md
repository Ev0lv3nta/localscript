# ADR 0005: воспроизводимые evidence и метрики

- Статус: принято
- Дата: 9 августа 2026 года

## Контекст

Одного поля `passed` недостаточно, чтобы оценить генератор: оно не показывает
ложно успешные ответы, эффект repair, нестабильность модели и разницу между
холодным и прогретым запуском. Результат без версии кода, хеша набора и данных
об окружении также нельзя независимо воспроизвести.

## Решение

Каждый benchmark формирует evidence schema v2. В неё входят SHA-256 набора,
результат каждого кейса, статус и стратегия, число обращений к модели, repair
rounds, длительности стадий и агрегаты syntax/semantic/verified completion.
Отдельно считаются invalid success и доля repair rescue. Latency разделена на
первый холодный запуск и p50/p95 прогретых запусков.

Release gate сохраняет commit SHA, признак чистого worktree, профиль и модель,
digest модели Ollama, версию драйвера и параметры GPU. Для release-кандидата
публичный набор выполняется трижды; нестабильный или не полностью успешный кейс
блокирует релиз. Закрытый holdout запускается только по явно переданному пути и
только после проверки его identity и отсутствия пересечений.

## Последствия

Публичные заявления должны ссылаться на конкретный release evidence, а не на
ручной локальный прогон. Изменение кода, корпуса или модели создаёт новый
эксперимент. Исторические regression-метрики не смешиваются с public benchmark
и private holdout.
