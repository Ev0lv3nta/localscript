# Манифест курируемого импорта

## Источник

Импорт выполнен из commit `d9489573c0e262dbdf11bc6bc5f5a5c6747abc1d` приватного репозитория `Ev0lv3nta/hackathon_mts_localscript`.

В новый репозиторий перенесены:

- Python-код приложения;
- тесты и eval-наборы;
- конфигурация и knowledge base;
- исходники локального web UI;
- runtime, benchmark и validation-скрипты;
- Dockerfile, Compose и Makefile;
- архив Lua 5.4.6, от которого пока зависит Docker build.

## Исключения

Намеренно не импортированы:

- исходная директория `.git`;
- `SUBMISSION.md` и `judge_ready.sh`;
- `scripts/build_submission_bundle.sh`;
- demo video;
- хакатонное описание C4, Mermaid-исходники и сгенерированные PDF, JPG и SVG;
- outline презентации и сценарий конкурсного demo;
- traces, sessions, runtime locks, caches и bytecode;
- старый README с judged-only инструкциями;
- служебные планы модернизации, отчёты моделей и agent briefs.

Исключённые бинарные материалы и полная старая история остаются в приватном архиве. Они не нужны для сборки текущего технического ядра.

## Контролируемые преобразования

- `.env.judge.example` переименован в `.env.example`;
- README заменён коротким описанием статуса модернизации;
- `.gitignore` и `.dockerignore` дополнены правилами для локального state и инструментов;
- из `kb/rules.yaml` удалены ссылки на локальные файлы организатора, а конкурсные названия профиля заменены нейтральными;
- восемь дословных публичных примеров и их KB-дубли заменены независимо написанными synthetic fixtures;
- добавлены тесты, запрещающие точное нормализованное пересечение prompt между KB и eval-наборами и возврат исходных публичных формулировок в текстовые файлы;
- добавлены MIT `LICENSE`, `THIRD_PARTY_NOTICES.md` и документы происхождения.

Эти преобразования не меняют runtime-код. Первый tag обозначает курируемый импорт, а не побайтовую копию хакатонной сдачи.
