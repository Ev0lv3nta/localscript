# Происхождение проекта

LocalScript начался как личный проект для задачи MWS Octapi на MTS True Tech Hack 2026. Целью прототипа была локальная агентная система, которая генерирует и проверяет Lua-код без отправки данных во внешние AI API.

Автор проекта — Николай Никитенко. Проект не занял призового места, поэтому предусмотренное правилами хакатона отчуждение исключительных прав команд-победителей к нему не относится.

Новый репозиторий не является официальным продуктом, проектом или репозиторием МТС/MWS. Названия организатора и задачи используются только для описания происхождения.
