# LocalScript

LocalScript — локальный сервис генерации и проверки небольших Lua-скриптов через Ollama. Проект умеет уточнять неоднозначные требования, проверять синтаксис и семантику результата и выполнять ограниченный цикл исправления.

Репозиторий создан из собственного прототипа для MTS True Tech Hack 2026 и сейчас проходит поэтапную модернизацию. Текущий baseline сохраняет полезное техническое ядро, но ещё не является публичным релизом: контракты ошибок, воспроизводимость установки, упаковка и оценка качества будут исправляться отдельными проверяемыми PR.

Исходный снимок и правила импорта описаны в [истории проекта](docs/history/hackathon-origin.md) и [манифесте импорта](docs/history/import-manifest.md).

## Статус

- Репозиторий остаётся приватным до прохождения release gate.
- Первый целевой релиз — `v0.2.0`.
- Главная гарантия будущего API: непроверенный Lua-код не возвращается как успешный результат.

Команды установки и запуска будут опубликованы после того, как они станут воспроизводимыми из чистого clone, wheel и контейнера.
